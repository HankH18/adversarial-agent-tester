# Contract changelog

All notable changes to the published inter-agent JSON Schemas in this directory.
Schemas are generated by [`scripts/export_contracts.py`](../scripts/export_contracts.py)
from [`adversaryforge.contracts`](../adversaryforge/contracts/__init__.py) and
guarded by [`tests/test_contracts.py`](../tests/test_contracts.py). See
[`README.md`](./README.md) for the versioning policy.

## v1 — initial published schemas

Initial published version of all seven inter-agent contracts:

- `CampaignDirective` — Orchestrator → Red Team
- `AttackAttempt` — Red Team → Judge
- `Verdict` — Judge → Observability / Documentation / Harness
- `ConfirmedExploit` — Judge → Documentation / Harness
- `RegressionCandidate` — Judge → Harness
- `VulnReport` — Documentation → Human / report store
- `AgentError` — every agent → Orchestrator / Observability

Each schema is JSON Schema Draft 2020-12, carries a `version: "v1"` marker and a
stable `$id` of `https://adversaryforge/contracts/<name>/v1`.
